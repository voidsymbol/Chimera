Instance-UI

The shadcn/ui catalogue, and MUI's, written on Instance: each component next to the original, with the count. Two halves. What the platform already has — a button, a dialog, a switch, an accordion, a menu — is a stylesheet on the native element and nothing else: no class, no script, no wrapper; the behaviour, the keyboard and the screen reader are the browser's. What the platform lacks — tabs, a combobox, a toast, a data table — is one class each, its own tag, on the platform's own primitives. No build, no dependencies, one file per component. Put class="ui" on a container and the native half is on.
